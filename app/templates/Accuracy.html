About the Summary Tables

From
Start of the evaluation window (UTC).
To
End of the evaluation window (UTC).
Number of Reached
Total assets with buy signal that hit predicted price.
Number of Predictions
Total predictions evaluated within the window.
Accuracy
Percent of predictions that were correct for that window.
12hrs / 4hrs Summary
Includes all signals in the interval.
12hrs / 4hrs Buy Summary
Subset that includes only “Buy” signals.
Auto-refresh
Each table refreshes every 30s with its own countdown.
Pagination
Use Prev/Next and Rows per page to navigate entries.
